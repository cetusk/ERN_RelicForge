# ビルド提案（試験的）のデータ

アプリの「ビルド提案」は、プレイヤーが選んだ **型（戦い方）・武器種・重視すること・定番のビルド** を、
遺物効果の条件（必須／推奨／任意／除外）に置き換えて、いつものビルド探索で組み合わせを探す機能。
このフォルダは、その変換ルール `resources/build_suggest.json` の元データと作成スクリプト。

情報源は [神攻略wiki（ELDEN RING NIGHTREIGN）](https://kamikouryaku.net/nightreign_eldenring/) のみ
（用語集・遺物効果・遺物・状態変化・各キャラページ・ビルド投稿）。本編（ELDEN RING）の情報や、
商業系の攻略サイトの情報は使わない。

## 使い方

```bash
# 元データを直したら作り直す（効果データの unreleased や名前を変えたときも）
python tools/build_suggest/build_data.py

# 確認用のレポート（Git 管理外）を作る
python tools/build_suggest/research/archetypes_gen.py    # → research/archetypes.md（型ごとの説明と効果の対応）
python tools/build_suggest/research/characters_gen.py    # → research/characters.md（キャラ別のビルド）
```

`python -m unittest discover -s tests` の `test_build_suggest` が、`resources/build_suggest.json` が
元データから作り直した結果と一致するかを確認する（作り直し忘れの検出）。

## ファイル

| ファイル | 内容 |
|---|---|
| `build_data.py` | `resources/build_suggest.json` を作る。どの型を選択肢にするか、武器種・つまみに使う効果もここで決める |
| `research/archetypes_content.py` | **型ごとの効果の対応**（中核／相性良／任意／避けたい）、別名、説明、出典 |
| `research/archetypes_gen.py` | 型のレポートを作る（効果のまとまり `PHYS` などの定義もここ） |
| `research/characters_gen.py` | **キャラ別のビルド**（174 件）、**キャラごとの定番の効果**、深層デメリットの評価 |
| `research/*_changes.md` | 調査の経緯（第1版からの変更点） |

## 変換ルール（アプリの `relic-suggest.js`）

| 入力 | 必須 | 推奨 | 任意 | 除外 |
|---|---|---|---|---|
| 型 | | 中核 | 相性良・任意 | 避けたい |
| 定番のビルド | そのビルドを決める効果 | 推奨 | 任意 | 避けたい |
| キャラの定番 | | 推奨 | 任意 | 避けたい |
| 武器種 | | ○○の攻撃力上昇 | 3つ以上装備・潜在する力 | |
| つまみ（火力 ↔ 生存） | | 寄せた側の汎用効果 | 中央なら両方 | |
| 深層デメリット | | | | Wiki で「避ける」とされるもの（通常のみでは使わない） |

- 同じ効果を使いたい選択と避けたい選択があれば、使いたい側を優先し、結果の画面で知らせる
- **未公開の効果（`effects_data.json` の `"unreleased"`）は使わない**（ネタバレ防止）。元データに含まれていると作成時に停止する
- 選んだキャラ以外の【キャラ名】効果は使わない。「通常のみ」では深層専用の効果を使わない
- 評価が割れている効果は「任意」に置く（中立）。キャラ全般で大事な効果は「キャラの定番」にまとめ、特定のビルドの必須にしない
- 「刀・出血」は武器種「刀」＋状態異常「出血」の組み合わせとして扱う（`combos`）。「特定戦技固定」「特定術の固定」は今後の詳細設定用で、選択肢には出していない

## 今後の予定

- ことば入力（「刀 二刀 出血」のような自由入力を別名の辞書で選択肢に置き換える）
- 戦技・術の固定（詳細設定）
- 「潜在する力」「出撃時の武器の…」が献器の最も左の遺物しか効かないことを探索で考慮する
