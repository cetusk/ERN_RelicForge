# キャラ別の評価と数値（付録）

キャラの特性（能力値・HP・回避・強靭度・カット率・状態異常耐性・スキルとアーツ・立ち回り）によって変わる遺物効果の評価。神攻略wiki のキャラページ（本文とコメント欄）と、キャラクター・ステータス・強靭度・基本アクション・遺物効果・アップデート情報のページから集めた（2026-11-01 調査）。

## 評価の使い方

- 本文の評価を主に使う。ビルド提案では除外の重みを「推奨」にする
- コメント欄の評価は、同じ評価の投稿が 3 件以上かつ反対の 2 倍以上あるときだけ使う（同じ人の連投は 1 件）。除外の重みは「任意」
- 本文の評価でも、最近のコメントがはっきり反対していれば（3 件以上かつ 2 倍以上）「割れる」として扱いを変えない
- 関係する性能変更より前の投稿は数えない（下の「版ごとの性能変更」。各表の「集計開始」がその日付）
- 条件付きの評価（「瓦礫ビルドなら」「重ね付けしなければ」など）と、本文どうしが食い違うものは使わない
- 全キャラ共通の評価（遺物効果ページの考察）と同じになるものは、共通の評価のまま

### 特性

- 能力値の特徴: 各種能力値がバランス良く成長するオールラウンダー。筋力・技量のバランス型で、あらゆる近接武器を扱え、直剣・大剣などでは全キャラ最高の攻撃力
- 回避: 標準的なローリング（無頼漢以外のローリング組と同じ）
- 耐久: 高い生命力と第六感で素でも生存力が極めて高く、深き夜でも遺物は耐久より攻撃力を優先。強靭度は、遺物効果ページの検証では +5 で訓練場の人形兵の突き1段目に怯まなくなる（+4 では怯む）
- アビリティ：第六感: 瀕死になる攻撃を一度だけ自動回避（祝福で再使用可、夜ボス・夜の王戦では一度限り）。スリップダメージ（毒/腐敗・遺物/付帯効果）、状態異常の発症ダメージ、掴み攻撃には発動しない
- スキル：クローショット: クールタイム8秒（遺物効果ページの計測で480F）。移動・接近・離脱・小型の引き寄せ・救助（1ゲージの半分）。無敵はない
- アーツ：襲撃の楔: 動作中無敵。ほとんどの敵の行動を怯みでキャンセル、2ゲージまで一撃救助。タメなしならゲージ3割残る
- 立ち回り: 得意武器は大剣。前線で継続的に攻撃し、ターゲットを取る
- 役割: 前衛のアタッカー。クローショットとアーツで救助もこなす

### 必須・重要な効果（参考）

- 必須：【追跡者】アーツ発動時、周囲を延焼（本文）: 延焼で3ゲージの味方を救助できる。マルチでは強く推奨
- 重要：【追跡者】スキルの使用回数+1（本文）: クローショットを2回ストックでき、1ゲージ救助も可能
- 重要：敵を倒した時、アーツゲージ増加（＋1）（本文）: アーツの回数を大きく増やせる。夜の王戦では効かない
- 重要：【追跡者】スキルに、出血の状態異常を付加（本文）: 雑魚を素早く処理でき、ファームが速くなる。慣れないうちは必ず入れたいというコメントもある
- 重要：物理攻撃力上昇+3/+4（深層）（本文）: 深き夜では耐久より攻撃力を優先。+4 を複数積む
- 重要：夜の侵入者を倒す度、攻撃力上昇（本文）: 深き夜では敵のHPが大きく上がるので攻撃力を上げることが重要
- あると良い：属性攻撃力上昇（深層）（本文）: 属性戦技ビルド（鎌など）で
- あると良い：大剣を3つ以上装備していると攻撃力上昇（本文）: 得意武器の大剣を3本揃えるのは難しくなく、二刀流が主な候補なので枠を圧迫しにくい。ただ運に左右される
- あると良い：封牢の囚を倒す度、攻撃力上昇（本文）: 攻撃力上昇の単体効果としてトップクラス（通常モード）
- あると良い：ダメージで吹き飛ばされた時、強靭度とカット率上昇 ＋ リゲイン（本文）: セットで、大型の敵の足元で殴り合える
- あると良い：戦技攻撃力上昇（本文）: 扱える武器が多く FP もあるので戦技特化に向く
- あると良い：潜在する力から、鎌／大槍／拳／大弓を見つけやすくなる（本文）: 武器種内の数が少なく、夜の王に合う武器を狙いやすい

- 能力値の特徴: 筋力と信仰に優れる。信仰Aでも FP は普通の近接並みで、祈祷メインは厳しい
- 回避: 通常はローリング。トランス中はステップに変わり、移動距離は長いが無敵は短い

- スキル：トランス: 8秒（CT14秒）：攻撃力+10%、カット率+35%、強靭度上昇、状態異常の蓄積約0.65倍、移動速度上昇、発動時スタミナ全回復、一定数命中で更に攻撃力+10%。強化版: アーツゲージ全消費で15秒間、全攻撃を自動回避（掴み、深海の夜、マリスの睡眠誘いは不可）

- 立ち回り: 筋力・信仰補正のある近接武器が主力で、トランスでスタミナと耐久の低さを補う。筋技のみの武器は追跡者・無頼漢に劣る。近接は必ず一撃耐える耐久を確保。表の固有効果はほぼ攻撃力上昇で、夜侵入と同じ遺物に収められる
- 役割: ファームでは怯ませ・致命で敵の攻勢を抑える。アーツでボスの危険行動を止める

### 意見が割れている点

- 被ダメージ時の蓄積デメリットの重さの順位（葬儀屋で）
  - 腐敗・毒は問題なし＞出血＞凍傷＞発狂・睡眠＞死（ゴリ押しすると死ぬ）
  - 発狂・睡眠が最悪＞＞＞出血・凍傷＞＞死＞毒・腐敗（死はカリゴ以外重くない）
  - 死は葬儀屋や無頼漢では重い時もある
- 被ダメージ時、睡眠（6820500）・すべての状態異常耐性低下（6850200）を葬儀屋で許容できるか
  - 葬儀屋はトランスの回避強化・状態異常耐性上昇があり、連続被弾に気をつければ問題ない
  - 睡眠は発狂と並んで最悪（動きが長く止まる）。耐性表でも葬儀屋の睡眠は低レベル帯で低め
- 【葬儀屋】技量上昇、生命力/信仰低下（6647400）の価値
  - 大槍・大槌・特大武器以外は基本ステ変推奨（特大剣もステ変した方が強い）
  - 生命力低下に見合わない・技量武器を振るのでなければ釣り合わない・葬儀屋が死にまくる原因の一部
  - 拳はコレクター版の表遺物で積めば生命が盛れてほぼデメリットなし
- 物理攻撃力の盛り方：本文の「深層は全部物理+3～4」か、耐久・立ち回り系優先か
  - 本文：全ての深層遺物に物理+3～4。デメリットのない+2以下での妥協は避ける
  - コメント：リゲインや攻撃時スタミナ回復、耐久などの方が優先では。このページが「葬儀屋は脆い」と言われる一因では
- 物理盛りか属性盛りか
  - 物理：大半の武器が純物理か物理と属性の複合で、アーツも純物理。腐らない
  - 属性：葬儀屋の固有バフは補助祈祷以外は属性も上げる。炎聖の筋力武器で頂点を取れる能力値
- アーツゲージ蓄積鈍化（6840200）
  - 便乗アーツがあるので他キャラより影響が少ない・撃破アーツ併用なら気にならない
  - 付けない
- 回避連続時、カット率低下（6850800）
  - 回避連打しなければ発動しない
  - トランス中は連続回避しがち・ボスによっては強要される
