# オーナー確認済みの事項（2026-10-28）

- 夜の魔術は存在しない（データにだけある効果で未公開）。「魔術（夜）」の型は削除した。
- 「周囲で睡眠状態の発生時、攻撃力上昇」は公開済の効果（Wiki に記載、セーブにも出現）。自分の睡眠でも発動する（執行者ページ）。
- 「周囲で毒／腐敗状態の発生時、攻撃力上昇」は自分の毒・腐敗でも発動する（執行者ページ）。瓦礫の中核に置いた。
- 評価が割れる効果（【無頼漢】スキル命中時、敵の攻撃力低下／【レディ】スキル使用時、僅かに無敵 など）は、どの型でも「任意」（中立）。
- 「咆哮とブレス強化」は竜餐の祈祷と執行者のアーツの咆哮に乗る。復讐者のファミリーには乗らない。
- 「刀・出血」は武器種「刀」＋状態異常「出血」の組み合わせとして扱う。「蘇生役」「回避型」「睡眠」「発狂」は残す。
- 「毒・腐敗」は「毒」と「腐敗」に分ける。祈祷の系統名は 獣・王都古竜・巨人の火・黄金律・神狩り とする。

# 未解決の事項

1. **凍傷ループの実効性**: 敵は状態異常を発症するたびに耐性値が上がる（状態変化）。何回ループすれば頭打ちになるか、夜の王相手に成立するかは定量情報が無い。
2. 三弓流投稿が挙げる付帯効果「射撃強化」「減衰軽減」がファイルに見当たらない。正式名称と、付帯効果データがどこまで網羅されているか。
3. 「ガード中、敵に狙われやすくなる」の詳しい仕様は、wiki でも「要検証」（仮説のみ）。
