- **出典は神攻略wiki（https://kamikouryaku.net/nightreign_eldenring/）のみ**: 用語集・遺物効果・遺物・状態変化・各キャラページ・魔術/祈祷/救助・固有遺物ページ・ビルド投稿。日付とバージョンの確認だけに公式アップデート情報を使った。商用攻略サイトや英語サイトの情報は使っていない。
- **未実装の遺物効果（`unreleased_candidates.json` の 95 件）は一切載せていない。** `gen.py` は、それらの key を参照したり、出力にその効果名が含まれたりすると停止する。
- 遺物効果名は `resources/effects_data.json` から **key 経由でスクリプト抽出**（手打ちなし）。id は同名・同 key の全 id を併記（未実装 id は除外）。

  - それ以外（3xxxxx=タリスマン/潜在等、8xxxxxx=武器の付帯効果と思われる）は「参考：遺物ではない」として別枠に記載。

- 階層の方針: 出典で評価が割れる効果（例: 【無頼漢】スキル命中時、敵の攻撃力低下／【レディ】スキル使用時、僅かに無敵）は **中核にも避けたいにも置かず「任意」**。ツールの推薦は中立を保つ。
- 武器種は **型ではなく独立した別軸**。「武器種特化」は参考項目として末尾に置き、`axis: weapon` とした。

## 重要事項（先に読んでほしい点）

1. **「攻撃連続時のカット率上昇」は遺物効果ではない。** `successiveAttacksNegateDamage` は id 8610700–8610702 のみで、武器の付帯効果。遺物で取れるのは「攻撃連続時、攻撃力上昇」「攻撃連続時、FP回復」。
2. 同様に **「ジャンプ攻撃強化」「タメ攻撃強化」「タメ攻撃中、カット率上昇」「二刀持ち攻撃力上昇」「両手持ち攻撃力上昇」「HP最大時、カット率上昇」「刺突カウンター強化」も遺物には無い**（付帯効果・タリスマン・潜在する力の側）。バッタなどの行動型は、遺物とは間接的にしかつながらない。
3. **「瓦礫」＝固有遺物「瓦礫の夜」の「状態異常ゲージがある時、徐々に攻撃力上昇」を、自分の状態異常ゲージで維持する型。** 「HP最大未満時、毒/腐敗が蓄積」などのデメリットは瓦礫では **相性良**、毒・腐敗型では **避けたい** と逆になるので、型を分けた。
4. **凍傷は「凍傷（維持）」と「凍傷ループ（炎で即解除して再発症）」の2型に分けた。** 炎ヒット系の効果は、前者で避けたい、後者で中核になる。
5. **「ハルハル」＝安寧の遺志（赤）＋安寧者の遺志（青）の2つ持ち**（近接攻撃力上昇・戦技攻撃力上昇）。戦技型の代名詞で、「片ハル」「赤ハル」「青ハル」「ハルハルガラス」「ハルハルサイス」も同系統。
6. **「夜侵入」「封牢（バフ）」** は全型共通の汎用火力枠で、型の判別には使えない（各型の任意〜相性良に入れている）。
7. 現行の深層デメリットにスタミナ系は無い。スタミナを多く使う型（バッタ・二刀流・連撃）の「避けたい」が空なのはそのため。
8. 系統強化（○○の魔術/祈祷を強化）は **深層の遺物にも付く**（遺物効果ページ FAQ）。データ上は同じ id で、深層専用の印は無い。
